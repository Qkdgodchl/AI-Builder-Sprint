# 🎮 픽셀 케어 (Pixel Care) 서비스 기획 & 핵심 기능 명세서 (PLAN.md)

## 🎯 1. 서비스 기획 배경 및 목적 (Service Vision)

### 1.1 문제 정의 (Problem Statement)
- **기존 봉사/기부 플랫폼의 한계**: 국가 자원봉사 포털이나 기부 사이트는 딱딱하고 이질적인 정형화된 UX를 가지고 있어, 1020세대 및 청년층의 자발적이고 지속적인 참여 유도가 어렵습니다.
- **선행에 대한 보상감 부족**: 봉사나 기부 참여 후 시각적, 감성적인 피드백이나 성취감이 부족합니다.

### 1.2 해결 방안 (Solution)
- **레트로 게이미피케이션 (Retro Gamification)**: 8-bit/16-bit 레트로 RPG 스타일의 픽셀 도감과 온기 온도계를 결합하여, 봉사와 기부를 하나의 "즐거운 게임 퀘스트"로 전환합니다.
- **AI 맞춤형 가이던스**: Upstage Solar LLM을 활용해 사용자의 위치, 시간, 감정에 적합한 봉사 미션을 대화형 마스코트(`Pixel AI Mate`)가 친근하게 추천합니다.

## 🚀 2. 4대 모듈별 핵심 기능 명세 (Core Module Specifications)

### 모듈 1. 🤝 봉사 & 기부 카탈로그 (`Volunteer & Donation`)
- **1365 자원봉사 공공데이터 연동**:
  - 행정안전부 1365 Open API (`schSido=6260000` 부산 지역)를 연동하여 실제 관내 봉사 목록 수신.
  - 상세 보기 클릭 시 1365 포털 원문 아웃링크 지원.
- **픽셀 펀딩 직접 등록 트랙**:
  - 사용자/지역 단체가 직접 봉사 또는 픽셀 기부 펀딩 프로젝트 생성 (`POST /api/volunteers`).
  - 기부 목표 금액 대비 현재 누적 펀딩 금액 달성률(%) 및 프로그레스 바 제공.

### 모듈 2. 💬 픽셀 커뮤니티 (`Pixel Community`)
- **범용 이야기 피드**:
  - 카테고리 분류: 전체 (`ALL`), 📝 봉사 후기 (`REVIEW`), 🤝 동행 모집 (`RECRUIT`), 💬 자유 수다 (`GENERAL`).
  - 제목 및 본문 키워드 실시간 검색 (`GET /api/posts?keyword=...`).
- **댓글 & 응원 하트 시스템**:
  - 게시글마다 소통 댓글 작성 및 목록 조회.
  - 응원 하트(❤️) 클릭 시 해당 게시글 좋아요 수 실시간 상승.

### 모듈 3. 🤖 AI 픽셀 메이트 (`Pixel AI Mate`)
- **Upstage Solar LLM 파이프라인**:
  - 사용자의 자유 입력(예: "해운대 근처에서 주말에 3시간 정도 환경 봉사하고 싶어")을 파싱.
  - 따뜻하고 친근한 레트로 픽셀 마스코트 톤앤매너로 답변 및 미션 카드 제안.
- **Smart Failover Engine**:
  - API 키 누락 또는 네트워크 단절 시에도 100% 정상 작동하는 동적 목업 폴백 로직 내장.

### 모듈 4. 🗺️ 성장의 길 & 온기 온도계 (`Pixel Roadmap`)
- **실시간 온기 온도계**:
  - 봉사 참여, 픽셀 기부, 커뮤니티 글/댓글 작성 시 온기 온도계 수치(+0.5°C) 실시간 상승 (최대 99.9°C).
- **S자 곡선 로드맵 & 뱃지 도감**:
  - LV1 (씨앗 용사) ~ LV5 (픽셀 마스터) 뱃지 해금 및 트로피 카드 보유 현황 제공.
  - Web Audio API 기반 8-bit 칩튠 효과음(버튼 클릭, 뱃지 획득, 온도 상승).
