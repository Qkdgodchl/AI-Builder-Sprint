## 🚀 2. Phase 1 최우선 메인 기능 명세 (Immediate Scope)

### 1. 🤝 봉사 & 기부 카탈로그 (`Volunteer & Donation`)
- **1365 자원봉사 공공데이터 연동**:
  - 행정안전부 1365 Open API (`schSido=6260000` 부산) 연동을 통한 실제 관내 봉사 수신.
  - 상세 보기 클릭 시 1365 포털 원문 아웃링크 연결.
- **픽셀 펀딩 직접 등록**:
  - 동네 봉사 및 픽셀 기부 펀딩 프로젝트 직접 등록 (`POST /api/volunteers`).
  - 기부 목표 금액 대비 현재 누적 금액 달성률(%) 및 프로그레스 바.

### 2. 💬 픽셀 커뮤니티 (`Pixel Community`)
- **이야기 피드 및 카테고리**:
  - 전체 (`ALL`), 📝 봉사 후기 (`REVIEW`), 🤝 동행 모집 (`RECRUIT`), 💬 자유 수다 (`GENERAL`).
  - 실시간 키워드 검색 (`GET /api/posts?keyword=...`).
- **댓글 & 응원 하트**:
  - 게시글마다 소통 댓글 작성 및 목록 조회.
  - 응원 하트(❤️) 클릭 시 하트 수 상승.

### 3. 🤖 Upstage AI 픽셀 메이트 (`Pixel AI Mate`)
- **Upstage Solar LLM 파이프라인**:
  - 사용자의 자유 입력을 파싱하여 맞춤형 봉사/기부 미션 및 추천 이유 답변.
- **Smart Failover Engine**:
  - API 키 누락/네트워크 장애 시에도 100% 정상 가동되는 동적 목업 폴백 로직.

### 4. 🗺️ 성장의 길 & 실시간 온기 온도계 (`Pixel Roadmap`)
- **실시간 온기 온도계**:
  - 봉사 참여, 픽셀 기부, 커뮤니티 작성 시 온기 온도계(+0.5°C) 실시간 상승 (최대 99.9°C).
- **S자 로드맵 & 뱃지 도감**:
  - LV1 씨앗 용사 ~ LV5 픽셀 마스터 뱃지 해금 및 Web Audio 8-bit 효과음.
